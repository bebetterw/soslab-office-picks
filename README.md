# 와이어즈 | 공간을 위한 모음집

청소·위생, 생활·안전, 가구·인테리어, 가전·조명, 주방·바베큐 품목을 모은 웹사이트입니다.

[공개 사이트 열기](https://bebetterw.github.io/soslab-office-picks/)

## 목록 기준

2026년 10월 23일 제공된 목록으로 기존 품목을 전부 교체했습니다.

- 전체 94개 품목
- 구매 링크 있음 69개: 일반 연결 13개, 근사 상품 56개
- 구매 링크 없음 25개: 가격과 구매 버튼을 표시하지 않습니다.
- 확인된 제품 사진 57개: 미확보 사진은 그 상태를 명시합니다.

가격과 구매 링크는 제공된 API 조회 결과이며, 판매 페이지를 검증한 정보가 아닙니다. 최종 가격·수량·규격은 판매 페이지에서 확인하세요. 근사 상품은 요청 구성과 다를 수 있습니다. 사진 출처와 확인된 차이는 상품 상세 화면에 기록되어 있습니다.

## 기능

- 품목 카테고리와 링크 상태별 필터
- 검색과 가격·이름 정렬
- 브라우저에 저장되는 즐겨찾기
- 상품 상세 설명, 근사 매칭 사유, 쿠팡 구매 링크
- 모바일 화면 지원

## 로컬 실행

```sh
python3 -m http.server 8000 --directory docs
```

브라우저에서 `http://localhost:8000`을 엽니다. 별도 설치나 빌드가 필요하지 않습니다.

## 파일 구성

- `docs/index.html`: 페이지 구성
- `docs/style.css`: 화면 디자인
- `docs/app.js`: 검색·필터·즐겨찾기·상세 보기
- `docs/products.json`: 품목과 출처
- `docs/images/`: 확인된 제품 사진

GitHub Pages는 `main` 브랜치의 `docs/` 폴더를 게시합니다. 저장소 이름과 기존 공개 주소는 링크 호환성을 위해 유지했습니다.

제품 사진과 브랜드의 권리는 각 권리자에게 있습니다. 구매 링크에는 제휴 추적 정보가 포함되어 있습니다.
